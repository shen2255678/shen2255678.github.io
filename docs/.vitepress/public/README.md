# Static Assets

This directory contains static assets that will be directly copied to the output directory during the build process.

In VitePress, the `public` directory is specially designed for static assets like images, fonts, etc.

To reference assets in this directory, use an absolute path starting with `/`. For example, if you have an image at `docs/.vitepress/public/images/logo.png`, you would reference it as `/images/logo.png` in your Markdown files.
